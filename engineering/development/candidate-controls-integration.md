## Packaging changes

The source archive's explicit reviewed allowlist now includes the current LCD/controls sources, original tests, viewer, and supporting documentation. New binary manifests use schema 2 with payload_profile=local-controls-v1 and require exactly the original six files plus libexec/brewpi-emulator-rmx/lcd-viewer.py. Packaging explicitly stages the existing lcd-viewer CMake component. The CMake default install and original core-v1/six-file profile remain supported; old saved packages continue to verify. An extra viewer without an explicit profile, unknown profiles, missing/changed helper bytes, and incorrect executable modes are rejected.

The helper is original MIT Python, with no new third-party code bundled. The default core executable remains independent of Python/Tk at runtime; choosing the graphical LCD requires the already documented external Python/Tk/desktop dependencies. Terminal controls and headless operation do not require Tk. No default display selection, Arduino wire identity, firmware action/reaction, store/checkpoint schema, or application version is changed here.
