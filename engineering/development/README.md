## Tools and layout

The foundation is C++17, CMake, a system compiler, the C++ standard library, and POSIX APIs. Python's standard library drives the six native suites, with no third-party JSON/controller runtime library. The separate opt-in milestone 4 fixture uses external host/browser dependencies declared in its requirements file and disposable test image. Actual exercised tool/image versions are recorded in the milestone provenance records, including [milestone 5](../licenses/milestone-5.md). Source belongs in src, independent tests in tests, future build helpers in cmake, future configuration/scenarios in config, and optional service templates in systemd. Generated binaries/reports/state belong in ignored directories. Follow root formatting files.

## Validation and provenance

Build and run CTest after relevant source/test changes. Use the sanitizer configuration for native memory/arithmetic checks; passing sanitizers are not AVR-equivalence or hardware evidence. Check changed documentation links, SPDX markers, whitespace, fixture preservation, and generated-output exclusions. Isolate ordinary validation from working BrewPi state/services/serial devices. The separate [host/panel integration fixture](../../docs/milestone-4.md) has its own external-client evidence and provenance; The [milestone 5 review](milestone-5-review.md) adds selected Linux qualification, staging, and operating evidence; physical Pi qualification and actual systemd activation remain outstanding.

The public repository is [brewpi-remix/brewpi-emulator-rmx](https://github.com/brewpi-remix/brewpi-emulator-rmx); local main tracks its HTTPS origin.
