# Tests

Future independently authored executable tests belong here. Milestone 1's [original protocol fixtures](../engineering/protocol/test-vectors/README.md) are specification data under engineering; no executable suite or fixture runner exists. The [plan](../IMPLEMENTATION_PLAN.md) defines acceptance gates. Preserve firmware behavior, including documented bugs, and do not treat characterization-required cases as passing. Existing host/panel programs may run as external clients; do not copy their tests or helper code.
