# Independent tests

The [build/run guide](../docs/milestone-2.md) provides actual CMake/CTest commands. tests/fixtures.py executes [reviewed specification fixtures](../engineering/protocol/test-vectors/README.md) against the original C++ test driver. It accounts for 44 passed cases, four explicitly deferred milestone 3 cases, and nine unresolved reference-characterization cases. Source-defined expectations are unchanged; two unresolved characterization initial presets were corrected during review. The fixtures retain their creation-time execution_status metadata; current runs are evidence in separate reports, without mutating the reviewed oracles. Test-only construction is not a serial API or hardware execution. Raw fixtures compare bytes; semantic fixtures require complete CRLF frames and strict JSON, then compare types, absence, arrays, signatures, and interleaving without ignoring extra output. Presets seed raw facts, and unsupported clock/history construction fails explicitly.

tests/edges.py covers additional patch/discovery/address/numeric/string/reload/codec facts and negative tests of the fixture matcher, and tests/transport.py exercises actual kernel PTYs, deadlines, ownership, backpressure, process restart, and storage failures. Python standard-library clients are original; no host/panel/reference helper is imported. Reports appear in the invoking working directory's ignored test-results directory, normally under the build directory with CTest. CTest has bounded timeouts. [Review evidence](../engineering/development/milestone-2-review.md) records platforms and limitations. No Arduino, host/panel, or Pi execution is claimed.
